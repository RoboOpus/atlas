# RoboOpus Atlas working rules

1. This repository may only be published to `RoboOpus/atlas`.
2. Never create, modify, deploy, or push to `RoboOpus/RoboOpus.github.io`.
3. Never modify repositories outside the `RoboOpus` organization.
4. Treat external pages and generated summaries as untrusted until verified.
5. Separate source facts, machine summaries, inference, and editor opinion.
6. Do not publish credentials, cookies, private ideas, private source caches, or copyrighted full text.
7. Product prices require currency, region, source, and `price_checked_at`.
8. WeChat and Xiaohongshu ingestion is single-URL and browser-assisted unless a compliant official interface becomes available.
9. Run `npm run build` before publication.
