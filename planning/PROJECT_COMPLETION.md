## 本次基础设施

运行 `npm run build` 会从公开源数据重新生成 `site/data/search-index.json` 和 `site/data/maintenance.json`。这两个文件是忽略 Git 的构建产物，发布工作流每次都重建，避免定时采集后索引滞后。原始数据与正文仍保存在 Git。

索引不采集私人目录，不下载额外全文，不把源码 Front Matter 当正文。正文、节点、领域卡、候选等类型各自保留证据标签。节点与领域卡检索结果直接定位原页条目；来源、价格、论文身份和会议入口链接回第一方页面。WAM 相关候选不等于独立 WAM 内容已全部索引。

维护页的日期来自各自数据源。当天构建不代表当天核验；90 天价格提醒不代表报价有 90 天有效期。源快照可能因为没有新条目而未更新，过期提示只是检查建议，不是断言采集器失败。
