# Atlas × WAM 联合检索

更新：2026-09-18。仅限 RoboOpus/atlas 与 RoboOpus/wam 项目站。

## 架构与覆盖

两个站各自发布公开 JSON 索引。Atlas 搜索页并行读取本地索引和固定的 WAM 公共索引地址，在浏览器里合并、检索与筛选，不上传关键词，也不读取私人 Lab 或收件箱。

- Atlas：原有正文、笔记、目录、候选、硬件等资料保持独立构建，当前 353 条。
- WAM：从实际页面使用的源模块导出 74 条，包括 26 条论文目录、2 篇完整原创正文、10 个领域地图板块、12 条 Benchmark、24 篇雷达候选。地图按板块聚合索引其所有条目文本，不以条目数冒充文章数。
- 当前两站共有 5 篇重复 arXiv 候选，联合结果为 422 条；数字随正常采集变化。

WAM 论文与评测结果直接定位到目录条目，正文跳到文章页。来源站可筛选 Atlas / WAM；跨站候选同时属于两个来源站，保留 WAM 记录入口。

## 不同证据不混为一谈

只有两边都属于候选、且有相同标准 arXiv ID 时才跨站去重。保留 Atlas 已有摘要文本与证据标签，追加 WAM 可搜索元数据。精读正文、论文目录和候选不互相合并；相似标题、共用代码库、Benchmark 同名也不能据此合并。

`article` 指可检索的正文，不自动等于人工终审或复现成功。WAM 已有精读样例保留作者报告、编辑判断、局限与未独立复现声明。新增类型 `publication` 表示论文目录，而不是出版/同行评审状态。

## 失败与隐私

WAM 加载最多等待 8 秒，拒绝未知版本、错误来源、重复 ID、非法链接、超大响应及无效字段。失败会明确提示；Atlas 索引独立可用。消费者只接收字段白名单，不执行来源提供的 HTML 或脚本。

WAM 请求使用固定公开 URL、无 Cookie、无 referrer，不含搜索词；匹配在本地执行。搜索词仍保留在当前页面 URL 便于分享，因此不要在公开检索输入私密内容。

Atlas 的下载 JSON 只包含本地索引，并不是跨站离线副本。WAM 在每次正常构建时重新生成索引；Atlas 页面重新加载后读取最新公开版本，不依赖另一次 Atlas 发布。索引生成时间、源数据核对日期和代码提交版本含义不同，未知日期不以当天日期填充。

## 验证与后续

WAM 测试覆盖来源集合完整性、正文检索文本、私密字段排除、所有静态路线及锚点。Atlas 测试覆盖契约拒绝、限时/限量加载、源站筛选、去重以及候选证据保留。跨仓库实际产物组合检查已检出 DreamZero 正文、RoboDojo 评测条目，并确认 5 个候选重复项。

仍未实现语义向量检索；联合索引不是联网论文搜索。下一步可配置按需检索将走发现流程，不混入当前已收录知识搜索。
