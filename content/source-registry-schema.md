# Atlas 可信来源注册表规范

`site/data/sources.json` 保存 WAM 以外五条建设线的首批可信入口。它回答“去哪里查”和“怎样接入”，不直接充当知识结论。

## 字段

| 字段 | 含义 |
|---|---|
| `id` | 稳定 ID，必须以板块名开头 |
| `track` | `frontier` / `robotics` / `hardware` / `adjacent` / `lab` |
| `name` / `owner` | 来源显示名与维护主体 |
| `kind` | API、标准、课程、文档、仓库、厂商、开源硬件、数据集或模板 |
| `access_mode` | `automatic` 自动增量、`assisted` 浏览器或解析辅助、`manual` 人工单链接 |
| `official` | 是否为该项目、产品或服务的第一方入口 |
| `url` | 原始 HTTPS 链接 |
| `best_for` | 该来源最适合解决的问题 |
| `reuse_note` | 许可、转载、版本、价格或核验边界 |
| `tags` | 搜索与跨板块关联关键词 |

## 编辑原则

- 官方页面、项目文档和作者仓库优先，聚合站只作发现线索。
- 收录来源不等于背书；事实进入知识条目前仍需交叉核验。
- API 与仓库可定时发现，动态文档和厂商页需要结构核验，受限平台保留人工单链接流程。
- 公开站只发布结构化事实、原创摘要和原链接，不镜像论文、文章、图片或数据集全文。
- 产品规格、价格、库存和软件版本必须携带核验日期；未知项保持未知。
- WAM 的来源与条目由 `RoboOpus/wam` 维护，Atlas 不复制其事实源。
