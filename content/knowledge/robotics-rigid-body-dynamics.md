## 标准方程只是一张接口图

固定基座机械臂常写为：

```math
M(q) qdd + C(q, qdot) qdot + g(q) + tau_f = tau + J(q)^T F_ext
```

`M` 是质量矩阵，`C qdot` 汇总速度相关项，`g` 是重力项，`tau_f` 是摩擦或其他未建模项，外力通过 Jacobian 转置映射到关节空间。Modern Robotics 从拉格朗日和 Newton–Euler 两条路线解释这些量，并延伸到任务空间与约束动力学。[S1]

方程的价值不在于背诵，而在于把系统查询分清：已知运动求力矩是逆动力学，已知力矩求加速度是正动力学，已知配置求 `M(q)` 是惯性查询。

## 三个核心算法

- **RNEA**：递归 Newton–Euler 算法，给定 `q、qdot、qdd` 计算关节力矩，常用于逆动力学和偏置项。
- **CRBA**：复合刚体算法，计算质量矩阵。
- **ABA**：关节体算法，给定状态和力矩计算关节加速度，适合正动力学。

Pinocchio 的官方能力表把运动学、动力学、Lie 群、解析导数和 Python 绑定放在同一模型接口中。[S2] Drake 的 MultibodyPlant 则提供另一条以系统建模、仿真和控制组合为中心的实现路径。[S3] 二者都不能替代模型核验：错误的惯性参数会被高效地算出错误答案。

## 质量矩阵应该满足什么

对常规刚体系统，`M(q)` 应对称，并在有效配置中正定。它描述不同关节加速度组合对应的动能：

```math
K = 0.5 qdot^T M(q) qdot
```

这给出两个简单测试：检查 `M` 与其转置的差，以及对随机非零 `qdot` 检查动能为正。若失败，先查惯性张量、质量、关节索引和浮动基座约定，而不是先换求解器。

## 重力补偿是最小真实实验

在低速、无接触条件下，给机器人施加 `tau = g(q)`，理想模型应抵消重力。真实系统仍会受到摩擦、齿隙、线缆、负载和安全控制器影响，因此验收需要：

- 明确负载质量、质心和安装姿态；
- 在多个安全姿态记录稳态误差与关节电流；
- 区分厂商控制器已做的补偿与上层算法输出；
- 从低增益、限幅和急停可达状态开始。

如果模型连静态重力都解释不了，直接上计算力矩控制或 NMPC 只会掩盖问题。

## 接触使方程多出约束

接触任务需要处理接触 Jacobian、法向约束、摩擦和冲击。刚性接触模型通常引入约束力或互补条件；柔顺模型则用弹簧阻尼近似局部形变。两者的参数都不是“仿真器默认值即真实值”。

接触丰富任务应记录求解器、时间步、摩擦模型、接触刚度/阻尼和穿透容差。否则不同算法在不同数值条件下的结果不可比较。

## 模型误差来自哪里

- URDF 惯性张量坐标系错误或不满足物理一致性。
- 夹爪、相机、转接板和线缆没有加入末端负载。
- 电机侧惯量和减速比未映射到关节侧。
- 静摩擦、库仑摩擦、黏性摩擦和回差被一个常数替代。
- 仿真与实机使用不同的关节零点、重力方向或控制周期。

系统辨识不是“把所有误差拟合掉”。需要先定义参数可辨识性、激励轨迹、训练/验证数据划分和模型有效域。

## 一组可自动化的模型测试

1. `M(q)` 对称且随机速度下动能为正。
2. `RNEA(q, qdot, qdd)` 与 `M(q)qdd + bias(q,qdot)` 一致。
3. 将 RNEA 结果送入 ABA，应恢复原始 `qdd`。
4. `qdot=0、qdd=0` 时，逆动力学结果与重力项一致。
5. 关闭重力与外力后，无驱动无耗散系统的总能量仅有受控数值漂移。
6. 同一 URDF 在两个库中的质量、质心、关节顺序和重力补偿结果一致。

通过这些测试后，模型才适合进入轨迹优化、MPC、阻抗控制或 sim-to-real 对照。
