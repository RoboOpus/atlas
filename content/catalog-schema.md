# Atlas 一级目录数据规范

`site/data/catalog.json` 只保存 WAM 以外五条建设线的一级知识节点。WAM 的论文、Benchmark 和方法数据继续由 `RoboOpus/wam` 维护，避免两套事实源。

## 字段

| 字段 | 含义 |
|---|---|
| `id` | 稳定 ID，必须以板块名开头 |
| `track` | `frontier` / `robotics` / `hardware` / `adjacent` / `lab` |
| `section` | 板块内的一级分区 |
| `title` / `title_en` | 中文显示名与英文术语 |
| `summary` | 该知识槽位要回答的问题，不代表已经完成的结论 |
| `priority` | P0 基础必建、P1 第二批、P2 后续补充 |
| `tags` | 搜索与跨板块关联关键词 |
| `next_step` | 下一次可执行的最小内容任务 |

## 状态边界

- Atlas 节点是导航与覆盖规划，不冒充已核验知识。
- 有论文、代码、产品或价格事实后，必须进入相应专题的数据模型并附来源。
- Lab 内容默认不公开；公开页面只能使用用户明确提供和批准的事实。
- 微信公众号、小红书只保存原创摘要、元数据与原链接，不公开镜像全文。
