# Robotics：机器人基础知识树

## 目标

建立从概念、数学、实现到实验和硬件的学习路径。第一轮先完成知识树，不追求教程篇数。

## 一级目录

1. **数学与动力学**：坐标变换、李群李代数、刚体动力学、接触模型、系统辨识。
2. **感知**：标定、检测分割、深度、6D 位姿、触觉、多模态融合。
3. **状态估计与建图**：滤波、优化、VO / VIO / SLAM、语义地图。
4. **规划**：图搜索、采样规划、轨迹优化、任务与运动规划、接触规划。
5. **控制**：PID、状态空间、最优控制、MPC、阻抗 / 导纳、鲁棒和自适应控制。
6. **学习与模型结合**：残差学习、学习动力学、可微规划、模型式强化学习。
7. **仿真与系统**：仿真器、ROS 2、实时系统、sim-to-real、安全约束。

## 每个主题的固定页面结构

1. 解决的问题与边界。
2. 最小数学表述。
3. 经典算法与现代变体。
4. 参考实现与测试用例。
5. 实验设置、常见失败与调参经验。
6. 与真实硬件的接口。
7. 与 WAM / VLA 的连接。

## 第一轮验收

- 七个一级节点和相互依赖关系明确。
- 每个节点至少列出经典入口、开源实现、练习建议三类资源槽位。
- 规划和控制不被泛化为“策略学习”的同义词。
