一条主线：配置到任务空间

串联机械臂的配置由关节变量 q 表示，正运动学把它映射到末端位姿 T(q)。这一步解决“机器人现在在哪里”，但控制和优化还需要知道：关节发生一个很小的变化时，末端如何变化。

Modern Robotics 用旋量和指数积公式统一旋转关节与移动关节，并区分在空间坐标系和末端坐标系表达的量。[S1] Pinocchio 则把运动学、Lie 群和解析导数实现为可计算接口，适合把公式落到模型测试中。[S2]

正运动学的两个常用表达

齐次变换连乘直观，适合从 URDF 或 DH 参数检查每级坐标系。指数积表达把每个关节写成零位形下的旋量：

T(q) = exp([S1]q1) exp([S2]q2) ... exp([Sn]qn) M

这里的 [Si] 表示旋量的矩阵形式，M 是零位形时末端相对基座的位姿。工程中不必执着于唯一参数化；真正重要的是明确零位形、关节正方向、基座和末端坐标系，并用同一组关节值交叉验证两种实现。

Jacobian 是速度映射

空间 Jacobian 把关节速度映射为在空间坐标系表达的末端 twist：

Vs = Js(q) qdot

对于 n 个关节的开链机器人，Js 是 6 × n。每一列可解释为“只有该关节以单位速度运动时，末端的瞬时 twist”。Modern Robotics 给出的递推结构说明，第 i 列只依赖它之前的关节配置。[S1]

本体 Jacobian Jb 则把同一个物理速度表达在末端坐标系。二者由伴随变换联系。混用 Js、Jb 和不同坐标系下的误差，是数值 IK 与控制器常见的隐蔽错误。

Jacobian 也映射力

虚功关系给出关节力矩与末端 wrench 的联系：

tau = J(q)^T F

这个式子仍要求 J 和 F 在同一坐标系、采用一致的 twist/wrench 排列。若线速度与角速度顺序不同，代码可能维度正确却物理意义错误。

奇异性不是一个“坏姿态”标签

当 Jacobian 的秩下降时，末端在某些方向上失去瞬时运动能力，或为了产生有限任务速度需要很大的关节速度。应至少同时检查：

  • Jacobian 的秩与最小奇异值；
  • 条件数随配置的变化；
  • 丢失的是哪个任务方向；
  • 关节限位与速度限制是否让理论可行方向实际不可用。

可操作度椭球比单一阈值更有解释力。对非方阵 Jacobian，“行列式接近零”也不是通用判断方法。

数值逆运动学的最小闭环

最基本的迭代是：计算当前位姿误差，映射为 twist，再通过伪逆求关节增量。接近奇异位形时可用阻尼最小二乘：

dq = J^T (J J^T + lambda^2 I)^-1 e

阻尼提高稳定性，但会引入任务误差。还需要处理步长、关节限位、姿态误差定义和停止条件。冗余机械臂可在零空间加入避限位、远离碰撞或改善可操作度的目标。

实现验收清单

  1. 零位形的末端位姿与 URDF/CAD 约定一致。
  2. 随机采样关节配置，旋转矩阵满足正交性且行列式接近 1。
  3. 用有限差分检查 Jacobian，每一列都能预测小关节扰动造成的位姿变化。
  4. 分别验证空间和本体表达，不在同一次误差计算中混用。
  5. 在已知奇异位形附近绘制最小奇异值，而不是只测试普通姿态。
  6. 数值 IK 同时报告末端误差、迭代次数、关节限位命中和最大关节增量。

常见失败模式

  • 把欧拉角差直接当作全局姿态误差，跨越角度分支时产生跳变。
  • URDF 中的关节轴、零位形或单位与手写模型不一致。
  • 把末端线速度 Jacobian 当成完整 6D Jacobian。
  • 用过小阻尼追求数值精度，导致关节速度在奇异点附近爆炸。
  • IK 收敛后不做碰撞、限位和路径连续性检查。
