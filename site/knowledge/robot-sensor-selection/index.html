  • 先写需要估计的物理量和失效条件，再选传感器。
  • 时间同步和外参误差常比标称分辨率更影响系统。
  • 视觉、力和触觉解决的信息不同，不能用单一精度数字比较。

从“需要什么信息”开始

传感器选型的第一行不应是品牌，而应是机器人需要估计的物理量：目标轮廓、表面深度、相机运动、全局几何、末端合力、接触分布、滑移或材料形变。不同传感器可能都输出“点云”或“力”，但测量机制、有效范围和失效方式完全不同。

建议为每个任务先写四个字段：

  1. 目标量：系统真正要估计什么。
  2. 时空范围：工作距离、视场、接触面积和更新频率。
  3. 允许失败：遮挡、反光、低纹理、冲击或饱和时如何退化。
  4. 下游接口：估计结果进入标定、建图、规划还是控制。

RGB-D 与双目视觉惯性

RGB-D 相机适合近距离几何、桌面操作和目标点云。选型不能只比较深度分辨率，还要看深度原理、最小/最大距离、视场、快门类型、环境光、表面材质、帧率、时间戳和 SDK。RealSense 产品族可作为主动或双目深度相机的官方型号入口，但每个型号的原理和供货状态需要单独记录。[S1]

ZED 产品族把双目、部分型号的 IMU、深度和定位软件放在同一生态中。官方文档说明，支持 IMU 的型号可将视觉与惯性信息结合，输出六自由度位姿、速度、时间戳和置信信息，并可接入 ROS 2。[S2] 这不意味着任何场景都能稳定定位：低纹理、动态物体、运动模糊和算力不足仍需实测。

两类设备的选择取决于任务：固定相机桌面抓取可能更重视近距离深度和外参稳定；移动机器人更关心时间同步、视觉惯性和长期漂移；高速操作还要关注曝光、运动模糊与端到端时延。

3D LiDAR

3D LiDAR 直接提供大范围距离采样，常用于移动机器人定位、建图和障碍物感知。Ouster OS 系列是当前登记的官方产品入口。[S3] 后续比较应固定具体型号与工作模式，并记录：线数或通道、垂直/水平视场、量程、最小距离、点频、旋转频率、反射率、时间同步、网络带宽、重量、功耗和防护等级。

LiDAR 的标称最大量程通常不是室内机器人的关键指标。更值得关注的是近距离盲区、玻璃和黑色材料、动态畸变、时间同步，以及传感器安装位置对遮挡的影响。

六维力/力矩

腕部六维力/力矩传感器测量三个方向的力和三个方向的力矩，适合力控、装配、接触检测和示教。ATI 的选型资料强调，量程必须同时考虑静态负载和机器人运动产生的动态力；分辨率表示系统能检测的最小载荷变化。[S4]

选型至少需要：

  • 末端、转接板和工件造成的静态力矩；
  • 加速、碰撞和插入过程的动态峰值；
  • 量程、分辨率与过载保护的平衡；
  • 采样率、滤波、通信和控制周期；
  • 安装变换、零点漂移和温度影响。

量程越大通常不意味着越适合精细操作，因为分辨小信号的能力也很重要。传感器位置越靠近法兰，越需要正确补偿末端重力和惯性。

视触觉

GelSight 一类视触觉传感器通过观察可变形接触表面获取局部几何和接触图像，适合纹理、滑移、接触位置和精细抓取研究。[S5] 它与腕部六维力传感器并不替代：前者提供局部分布和形状，后者提供整体合力与力矩。

视触觉系统需要额外记录接触表面材料、照明、相机标定、帧率、接触面积、耐久性和更换成本。论文中的视觉效果不等于长期机器人实验中的稳定性。

同步与标定是系统主线

多传感器系统必须把时间和坐标系作为一等数据。至少保存：

  • 原始硬件时间戳、主机接收时间和同步方法；
  • 相机内参、畸变和分辨率；
  • 每个传感器到机器人基座或末端的外参方向；
  • 标定方法、数据、残差和核验日期；
  • 驱动、固件、SDK 和 ROS 消息版本。

如果相机与机器人状态相差 50 ms，在快速运动中即使外参完美，也会产生明显空间误差。若把软件滤波后的时间戳误当成曝光时间，离线回放可能无法复现在线行为。

最小验收实验

  1. 静态重复性：固定场景连续运行，记录漂移、噪声和温升。
  2. 边界条件：测试最小距离、最大距离、低纹理、反光、黑色表面或冲击。
  3. 同步检查：设计快速可观察运动，估计不同数据流的时间偏移。
  4. 外参闭环：通过不同变换链到达同一坐标系，检查闭环误差。
  5. 负载与饱和：力传感器使用真实末端与工件，检查静态偏置和动态峰值。
  6. 持续运行：记录丢帧、重连、驱动崩溃、带宽和散热。

RoboOpus 的传感器知识库后续不会把 RGB-D、LiDAR、力和触觉压进一张“精度排行榜”。它们将按测量原理分表，并通过共同的时间、坐标、接口和失效字段连接成完整感知系统。
