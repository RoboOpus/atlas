Source pipeline

来源按稳定性分级接入

自动化程度由来源条件决定；“能读取”不等于“适合无人值守抓取”。

自动

arXiv / GitHub / RSS

使用公开 API、Feed 与 Sitemap 做增量发现，保存标识符、时间和原链接。

半自动

普通网站 / 动态页面

优先正文解析；必要时由浏览器辅助读取，再由人工核验页面结构和许可。

单链接

微信公众号 / 小红书

由你提供公开链接，在已有登录会话中读取可见内容；公开站只发原创摘要和回链。

Editorial workflow

先收录，再验证，再形成观点

  1. 01收录

    保存原始链接、日期与来源类型。

  2. 02核验

    对照论文、项目页、代码与官方资料。

  3. 03结构化

    归入统一字段与知识树，保留未知项。

  4. 04评述

    标明证据、推断与个人观点，不混写。
