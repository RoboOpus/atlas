把值得保留的链接，
交给知识库。

先存本地，再整理证据，最后明确选择是否公开。这个静态页面不接收在线投稿，不读取登录态，也不会自动抓取你输入的网站。

下载文件包含你填写的链接与备注；不要提交到公开仓库或公开 Issue。微信、小红书链接可能含临时参数，只供本地辅助读取。

启用 JavaScript 后可生成本地文件；内容不会自动发送到服务器。

从链接到知识的实际流程

  1. 下载请求文件，或直接在对话中提供链接。私人链接请明确标注。
  2. 在 Atlas 工作区运行 npm run inbox -- import --file=下载文件路径，进入 Git 忽略的本地收件箱。
  3. 普通公开网页可读取标题与描述；登录页、微信和小红书由浏览器辅助读取单篇。遇到限制就保留为“需要辅助”，不绕过。
  4. 整理原创摘要、来源陈述、编辑推断、证据链接和局限，不复制全文或图片。
  5. 预览公开字段后，用显式 publish --public 导出公开草稿；构建测试通过后才发布。公开草稿仍不等于人工科学审核。
